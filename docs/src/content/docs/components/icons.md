# Icons (`icons.rs`)

Loads icons from freedesktop.org icon themes with fallback chains and caching.

## Choosing an icon theme

Settings → Personalization → **Themes** lists every installed icon theme (from
`~/.local/share/icons`, `~/.icons` and `/usr/share/icons`) with a row of its icons to compare,
and "System default" (KDE's theme, else Breeze). The choice is `icon_theme` in settings.conf.

- The compositor (taskbar, Start, titlebars, tray) and vide-desktop switch at once; File
  Exploder, Task Mangler and Snip & Sketchy use it next time they open.
- Every program asks `vide_config::themed_icon` first, which reads the theme's `index.theme`
  (its folders, their sizes, what it inherits). Whatever the theme lacks is filled in from the
  system's theme (KDE's, else Breeze), then from our own `vide` pack, so a theme with gaps
  never leaves a blank. The Themes page shows a filled-in icon faded, so you can see what a
  theme is missing. Apps that aren't ours follow KDE's or GTK's icon settings, not this one.

**Use the selected theme's system icons instead of VIDE's** (a toggle on the same page,
off by default): the taskbar's Wi-Fi, volume, brightness and Action Center icons come from the
chosen theme instead of VIDE's own glyphs. It looks in the theme's panel (`status`) icons, its
one-colour `-symbolic` versions first, and in its `-dark` variant on a dark taskbar (Win11 has
`Win11-dark`). Any the theme lacks, or that come out empty (SVGs wrapping a bitmap, which we
can't draw), stay VIDE's.

For a Windoze look, install an icon theme into `~/.local/share/icons` and pick it. Neither
ships with VIDE-DE:

- **Windows 10** ([B00merang-Artwork/Windows-10](https://github.com/B00merang-Artwork/Windows-10)):
  the classic Windoze 10 (LTSC) set. A plain theme folder; clone it into
  `~/.local/share/icons/Windows-10`. It covers most of what we use; the rest is filled in.
- **Win11** ([yeyushengfan258/Win11-icon-theme](https://github.com/yeyushengfan258/Win11-icon-theme)):
  GPL-3; install with its `install.sh`.

## The `vide` theme

VIDE-DE ships one theme of its own, `vide` ("VIDE" in the list): flat, Windoze-like icons for
the folders, file types, our apps and File Exploder's toolbar. It isn't used unless picked.

- It's `assets/icons/vide/` (`index.theme` plus scalable SVGs), inheriting Breeze and hicolor.
  The compositor carries it inside itself and installs it to `$XDG_DATA_HOME/icons/vide` at
  login, removing any icon it no longer has.
- The SVGs are generated by `scripts/make-icons.py`; change the script and run it again, which
  also rewrites `src/icon_pack.rs` (the list the compositor embeds). Don't use `<text>` in
  them: vide-desktop and the compositor render SVGs without fonts.

## Theme Discovery

```rust
fn find_icon_themes() -> Vec<PathBuf> {
    let mut themes = Vec::new();
    
    // System themes
    themes.extend(glob("/usr/share/icons/*/index.theme"));
    themes.extend(glob("/usr/local/share/icons/*/index.theme"));
    
    // User themes
    if let Some(home) = dirs::home_dir() {
        themes.extend(glob(&home.join(".icons/*/index.theme")));
        themes.extend(glob(&home.join(".local/share/icons/*/index.theme")));
    }
    
    // Fallback: hicolor
    themes.push(PathBuf::from("/usr/share/icons/hicolor"));
    
    themes
}
```

## Icon Lookup Algorithm

```rust
fn lookup_icon(theme: &IconTheme, name: &str, size: u32) -> Option<PathBuf> {
    // 1. Exact match in theme
    if let Some(path) = find_in_theme(theme, name, size) {
        return Some(path);
    }
    
    // 2. Scalable (SVG) in theme
    if let Some(path) = find_scalable(theme, name) {
        return Some(path);
    }
    
    // 3. Parent themes (Inherits chain)
    for parent_name in &theme.inherits {
        if let Some(parent) = load_theme(parent_name) {
            if let Some(path) = lookup_icon(&parent, name, size) {
                return Some(path);
            }
        }
    }
    
    // 4. hicolor fallback
    if theme.name != "hicolor" {
        return lookup_icon(&hicolor_theme(), name, size);
    }
    
    None
}
```

## Caching

```rust
struct IconCache {
    loaded: HashMap<String, IconData>,  // key = "name:size"
    surfaces: HashMap<String, MemoryRenderBuffer>,
}

impl IconCache {
    fn get(&mut self, name: &str, size: u32) -> Option<&MemoryRenderBuffer> {
        let key = format!("{}:{}", name, size);
        self.surfaces.get(&key).or_else(|| {
            let path = lookup_icon(&current_theme(), name, size)?;
            let data = load_image(&path)?;
            let buffer = upload_to_gpu(&data);
            self.surfaces.insert(key, buffer);
            self.surfaces.get(&key)
        })
    }
}
```

## SVG Support

Uses `resvg` for rasterizing SVG icons:

```rust
fn load_svg(path: &Path, size: u32) -> Result<IconData> {
    let tree = usvg::Tree::from_file(path)?;
    let mut pixmap = tiny_skia::Pixmap::new(size, size).unwrap();
    resvg::render(&tree, usvg::FitTo::Original, pixmap.as_mut())?;
    Ok(IconData {
        pixels: pixmap.take().to_vec(),
        width: size,
        height: size,
        has_alpha: true,
    })
}
```

## Configuration

```ini
[icons]
theme = "Adwaita"  # or "Papirus", "Tela", etc.
fallback-theme = "hicolor"
default-size = 24
```
